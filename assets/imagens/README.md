# Imagens

Pasta destinada a sprites, fundos, icones e outros elementos visuais.

## Conteudo atual

- `spritesheet.bmp`: spritesheet base do template (não é usada pelo jogo).

O jogo não usa imagens desta pasta: o fundo, o HUD e os cartões são desenhados por código em `src/interface.py`. A origem e a licença de cada recurso externo ficam registradas na seção "Recursos externos" do README principal.

## Recomendações

- Separe imagens por tema quando o projeto crescer.
- Mantenha dimensoes e padroes consistentes para facilitar colisao e animacao.
- Prefira formatos com transparencia quando necessario (ex.: `.png`).
